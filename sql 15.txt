limit :
it is used to print specific num of rows from given value.
it works from first ---> last

syntax :
select column_name/expression
from table_name
limit value;

offset:
-------
it is used to skip or ignore some specific num of rows

syntax:
select column_nmae/expression
from table_name
limit value offset value;

2. charater functions 

characteristics:
-----------------
> it takes n num of inputs and generate n number of outputs.
> if it executes row by row
> we can nest character functions
> we can use character functions inside where clause.

types of character functions :

1. lower():
it is used to convert a string into lowercase

select lower("MANJA");

select lower(fname)
from emps;

2. upper():
it is used to convert a string into uppercase

select upper("ramya");

3. length():
it is used to print number of charaters present in string

select length("pentagon");

4. reverse():
it is used to print given string in reverse format.

select reverse("I love you");

5. concat():
it is used to add/combine 2 or more strings

syntax:

concat("str1","str2"......"strn")

syntax:

concat(col1,col2,col3.....coln)

select concat("hey"," ", fname)
from emps;
